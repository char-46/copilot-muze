# 摘要简报规范

用户要求「总结未读」「给我简报」「XX 群聊了啥」时：

1. 定范围：
   - 「未读/最近」→ `cli({"command": "unread"})` 看活跃会话，用户点名哪个就总结哪个；
   - 没点名 → 挑最近 24h 最活跃的 2~4 个会话。
2. 取内容：`get_recent_messages`（30~60 条）；图片多且与话题相关时用 `describe_image`（最多 3 张）。
3. 输出格式：
   - 每个会话一小节：`## <会话名>`；
   - 要点式（谁 + 什么事 + 关键结论），控制在 5 条以内/会话；
   - 末尾统一「待办/需回复」清单（哪条消息在等被控号回复）；
   - 控制在 500 字内，宁可精炼不要灌水。
4. 周期任务（如「每 2 小时简报」）里同样按本流程，但只报「上次简报之后的新消息」（参考任务 prompt 里给的时间点）。
